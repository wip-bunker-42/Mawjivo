# دليل تحقق مرشح 0.1.1

في 14 أكتوبر 2026 طلب المالك جعل المستودع عامًا ونقله إلى منظمتِه الوحيدة. تم النقل إلى `wip-bunker-42/Mawjivo` بعد فحص 1928 كائن Git و861 ملفًا تاريخيًا عبر جميع المراجع، مع فحص قيم 16 عائلة اعتماد موجودة لدى المالك، دون العثور عليها في السجل. بقيت أسرار البناء في GitHub Secrets والملفين المحليين. عُدلت الأرشفة لقبول المستودع العام مع نفس شروط التوقيع والمصدر والأصول الأربعة المنقحة؛ نجحت 13 حالة للأرشفة و123 اختبار سكربت مع التخطيين القديمين. ينتظر تشغيل المصدر الجديد التحقق الفعلي من البناء على GitHub بعد النقل.

الحالة: لم يُفعّل أول إصدار إنتاج. لا تُستنتج نتيجة اختبار Windows من رمز خروج المشغّل وحده؛ يلزم دليل القبول الذي يقارن بصمة التطبيق المثبت ببصمة تثبيت مستقل لنفس الحزمة، ويربط النتيجة بمصدرها ونسختها وبصمة المثبت.

ثبت قبول ملف حسابات المالك إلى قاعدة SQLite وخزنة Windows معزولتين وفارغتين يوم 14 أكتوبر 2026: خدمة واحدة ومساحة واحدة وثلاثة اتصالات. نجح الاستيراد المتكرر وإعادة التصدير، وبقيت معرفات الخدمة والموارد والمساحات والحسابات والمنشورات متطابقة، وقرئت أحدث إعدادات الخدمة، دون كتابة إلى Cloudflare. حُذفت بيانات الاختبار ومراجع الخزنة التي أنشأها الاختبار فقط.

نجح [CI للمصدر 939da29f](https://github.com/wip-bunker-42/Mawjivo/actions/runs/38518870921) بعد فحص الأنواع والبناء والواجهة والاختبارات الأصلية. شمل التحقق المحلي 54 اختبار واجهة و103 اختبارات Rust. آخر مجموعة سكربتات بعد إضافة شرط دليل القبول: 112 ناجحًا وتخطيان قديمان. نتائج المجموعة المحلية هذه تخص تعديل المشغّل على المصدر 2985b4d، وليست قبول حزمة مثبت جديدة لذلك المصدر.

أكمل [قبول Windows الفعلي 38554392617](https://github.com/wip-bunker-42/Mawjivo/actions/runs/38554392617) التثبيت النظيف والتحديث عبر أزرار التطبيق وإعادة فتح المسودة على الحزم الموقعة للمصدر `939da29f4678d48d6e47415930c325ecbefd20a1`. قُرئ ملف `acceptance-proof.json` وتحقق منه مستقلًا: بقيت الحسابات والمسودة والخزنة، وأنشئت نسخة احتياطية، وتطابقت بصمة ملف التطبيق بعد التحديث مع تثبيت نظيف مستقل لنفس المثبت. بصمة المثبت `c98b4acf024053f3a3ce1e63cdcdb3a8cea45c746f4cf97628bb920467aaf84b`، وبصمة ملف التطبيق المرجعي والمحدث `9927b2510f1d9857e93e3778b85521c6216a4583be8aefccae1f7fc6c768bb76`.

كان [تشغيل البناء الأصلي 38519665608](https://github.com/wip-bunker-42/Mawjivo/actions/runs/38519665608) قد توقف عند بدء التثبيت دون دليل، فمنعت الأرشفة إنشاء Release أو تفعيل الإنتاج. أعاد القبول الناجح اختبار بايتات الحزمة نفسها مع تشغيل Node مباشرة وانتظار اكتماله بدل الاعتماد على نتيجة غلاف الصدفة، ثم تحقق من ملف الدليل. لا يُنسب قبول هذه الحزمة إلى مصدر أحدث؛ يجب إعادة البناء والقبول للمصدر النهائي بعد المراجعة.

اكتملت المراجعة المستقلة المجملة لنقل الإعدادات والإصدارات. أصلحت أربع ملاحظات مؤثرة باختبارات فشل ثم نجاح: تعارض التنظيف مع ناشر محلي، وأصل GitHub الفارغ بعد فشل الرفع، وتوقيع مصدر غير محفوظ في Git، وتمرير وضع قبول الاختبار القديم إلى فحص الدليل. نجحت 32 حالة مركزة للإصلاحات. وأثبتت تجربة على R2 الحقيقي منع مشغّل ثانٍ ثم نجاحه بعد تحرير القفل، دون رفع حزم أو تغيير ملفات تحديث أو حذف ملفات. بقي تحسين صغير مؤجل: تحديد الخدمة المعطلة داخل رسالة فشل التصدير عند وجود عدة خدمات.

اكتمل التحقق المحلي بعد الإصلاحات: فحص الأنواع والبناء وتوافق النسخ والأدوات، و122 اختبار سكربت ناجح مع تخطيين قديمين، و103 اختبارات Rust مع rustfmt وClippy، و54 اختبار واجهة. يلزم الآن CI وبناء المصدر النهائي وقبوله نفسه وأرشفة التجربة العامة، ثم تثبيت مرشح المالك بعد حفظ قاعدة البيانات والتأكد من عدم وجود رفع نشط. تبقى تجربة المالك لـNVDA ومعايير المهمة 16 الباقية مطلوبة قبل وسم `v0.1.1` وتفعيل رابط الإنتاج العام.
