# Mawjivo 0.1.2

نُشر الإصدار المستقر يوم 15 أكتوبر 2026. [تنزيل مثبت Windows](https://github.com/wip-bunker-42/Mawjivo/releases/download/v0.1.2/Mawjivo_0.1.2_x64-setup.exe) أو [عرض ملفات الإصدار](https://github.com/wip-bunker-42/Mawjivo/releases/tag/v0.1.2).

ينتقل فحص تحديثات التطبيق وتنزيل مثبت Windows إلى GitHub Releases العامة، مع توقيع التحديث والتحقق من النسخة والحجم. ينشر GitHub حزمة موقعة كمرشح تجريبي أولًا، ثم يجعلها أحدث إصدار مستقر بعد نجاح اختبار Windows الفعلي وبقاء البيانات. يتوقف رفع حزم التطبيق الجديدة إلى مخزن Cloudflare.

يتطلب الانتقال من 0.1.1 تثبيت المثبت الجديد من GitHub مرة واحدة فوق النسخة الحالية؛ بعدها تعمل التحديثات التالية من GitHub داخل التطبيق. تظل خدمة Cloudflare مسؤولة عن النشر الاجتماعي والجدولة والوسائط.

الحالة الحالية وأدلة الاختبار والتنزيل في [سجل التحقق](0.1.2-verification.md). راجع [التثبيت](../user/install.md) و[التطوير](../user/development.md).
