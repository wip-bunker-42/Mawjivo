# Mawjivo 0.1.1 — مرشح للتسليم

تضيف النسخة تصدير الإعدادات والحسابات واستيرادها إلى جهاز جديد بملف ENV واضح، مع التحقق من ملكية خدمة Cloudflare قبل إرسال مفتاح الجهاز. يعيد الاستيراد ربط الجهاز بنفس الخدمة، ويقرأ أحدث المساحات والحسابات والتفضيلات والمنشورات المجدولة. تكرار الاستيراد لا ينشئ خدمة أو حسابات إضافية. المسودات المحلية وملفات الصور والفيديو لا تدخل ملف النقل.

ملف التطوير واضح ومنفصل، ويحتوي على مفاتيح التوقيع والنشر ودخول GitHub الموجود لمواصلة العمل بعد الفورمات. تحفظ GitHub Releases العامة المثبت الموقّع ودليل قبوله، وتوفر Cloudflare النسخة نفسها للتنزيل والتحديث داخل التطبيق. تحتفظ سياسة التنظيف بأحدث إصدارين مفعّلين والإصدارات المشار إليها والحزم الحديثة، وتحصر الحذف في حزم التطبيق وتوقيعاتها المعروفة.

أصبح مثبت Windows يعمل بالعربية تلقائيًا دون نافذة اختيار لغة تتسبب في انتظار التحديث غير التفاعلي. يتحقق اختبار الإصدار من التحديث الفعلي وبقاء الحسابات والمسودة وخزنة Windows، ويشترط ملف دليل مكتمل قبل النشر.

تربط الحزمة المصححة نافذتي تصدير الإعدادات واستيرادها بنافذة التطبيق، وتضع الزرين تحت بعض. أكد المالك نجاح التصدير؛ جرى فحص الإصلاح والتحديث الفعلي على GitHub Windows قبل تسليم المثبت الموقّع المصحح.

تتوفر [الحزمة التجريبية المتحققة على GitHub Releases](https://github.com/wip-bunker-42/Mawjivo/releases/tag/acceptance-v0.1.1-d9a18e95) دون تسجيل دخول، وثُبّتت على جهاز المالك. هذه ملاحظات مرشح، وليست إعلان إصدار مستقر. يوضح [سجل التحقق](0.1.1-verification.md) أدلة البناء والتحديث الفعلي وما بقي؛ أول إصدار إنتاج ينتظر معايير التسليم الباقية. راجع [التثبيت](../user/install.md)، و[الاستعادة والنقل](../user/recovery.md)، و[مواصلة التطوير](../user/development.md).
