# Mawjivo 0.1.0

الإصدار الأول للنشر الشخصي من Windows، بواجهة عربية داكنة ومساحات عمل مستقلة.

- نشر النص والصور والفيديو على قنواتك المتاحة في Meta وBuffer، مع مراجعة عربية للتغييرات قبل الموافقة.
- تجهيز الصور والفيديو محليًا، ورفع النسخ المطلوبة مرة واحدة، وجدولة Cloudflare وتعديل المنشورات المجدولة وإلغاؤها.
- سلاسل متصلة لـThreads وX، ونشر YouTube Shorts عبر Buffer.
- ملخص للاستخدام، وتقارير عبر بوت تليجرام الخاص بك، ومراقبة Healthchecks مستقلة.
- تحديثات موقّعة بطلبك، مع حفظ البيانات والنسخ الاحتياطية قبل الترقية.

يستخدم كل شخص حساباته وموارد Cloudflare الخاصة به. تبقى حدود خطط الخدمات وصلاحيات المنصات شرطًا للنشر. Windows هو نظام التسليم الأساسي؛ يعتمد تسليم macOS وLinux على اكتمال اختبارات وتوقيع توزيعهما.
