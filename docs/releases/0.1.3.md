# Mawjivo 0.1.3

نُشر [الإصدار المستقر 0.1.3](https://github.com/wip-bunker-42/Mawjivo/releases/tag/v0.1.3) يوم 19 أكتوبر 2026. يمكن تنزيله من GitHub أو اختيار «فحص التحديثات» من «الإعدادات ← التحديثات» في النسخة 0.1.2.

إصدار صيانة يزيل مكتبة ZIP غير المستخدمة من مسار تحديث التطبيق. تظل تحديثات Windows مثبتات NSIS موقعة بصيغة EXE، مع فحص التوقيع والنسخة والحجم وحفظ البيانات قبل التثبيت. تبقى إعدادات TLS والوكيل كما هي.

يعالج التغيير تنبيهات `RUSTSEC-2026-0367` و`RUSTSEC-2026-0368` و`RUSTSEC-2026-0369` بإزالة الاعتماد المتأثر ومسار استخراج ZIP من البناء. أصلح كذلك تجهيز موارد الفحص على Linux وmacOS، وقلل تكرار تشغيل CI للفرع نفسه. لا يتطلب تغيير حسابات النشر أو خدمة Cloudflare أو إعداداتها.

نجح الفحص الكامل على GitHub، والتجميع على Linux وmacOS، واختبار Windows للتثبيت والتحديث الموقّع الفعلي وحفظ البيانات. جرى فحص الملفات المنشورة وتواقيعها وبصماتها من روابط GitHub العامة. النتائج التفصيلية وحدود التدقيق، بما فيها تنبيه GLib المتبقي على Linux، في [سجل التحقق](0.1.3-verification.md).
