# Mawjivo 0.1.3

إصدار صيانة لإزالة مكتبة ZIP غير المستخدمة من مسار تحديث التطبيق. تظل تحديثات Windows مثبتات NSIS موقعة بصيغة EXE، مع فحص التوقيع والنسخة والحجم وحفظ البيانات قبل التثبيت. تبقى إعدادات TLS والوكيل كما هي.

يعالج التغيير تنبيهات `RUSTSEC-2026-0367` و`RUSTSEC-2026-0368` و`RUSTSEC-2026-0369` بإزالة الاعتماد المتأثر ومسار استخراج ZIP من البناء. لا يتطلب تغيير حسابات النشر أو خدمة Cloudflare أو إعداداتها.

الحالة وأدلة الاختبار والنشر في [سجل التحقق](0.1.3-verification.md). سيظل الإصدار المستقر السابق متاحًا حتى يجتاز المرشح اختبار التحديث الموقّع الفعلي على Windows.
