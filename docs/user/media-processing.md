# معالجة الوسائط في Mawjivo

المعالجة على جهازك. لا يغير Mawjivo محتوى الملف الأصلي أو اسمه؛ ينشئ نسخة منفصلة عندما تتطلب منصة صيغة أو حجمًا أو مدة أو أبعادًا مختلفة. يوضح ملخص الموافقة التغييرات قبل الإرسال.

تحافظ الصورة الأصلية على اسمها عند رفعها وإرسال رابطها. نسخة JPEG تحمل جذر اسم الصورة وامتداد `.jpg`. قد تعيد المنصة تسمية ملفها الداخلي بعد الاستلام؛ لا يستطيع التطبيق التحكم في ذلك.

يُستخدم عنوان الفيديو لإنشاء اسم الإرسال، حتى عند استبعاد يوتيوب. تزال رموز أسماء الملفات المحظورة في Windows، وتبقى الحروف العربية والرموز التعبيرية كاملة. يبلغ الحد الآمن للاسم 180 وحدة UTF-16، شاملًا الامتداد، ويظهر اسم الإرسال في التأكيد.

نسخ الصور تبدأ بجودة JPEG مقدارها 95. يخفض التطبيق الجودة فقط إن تجاوز الملف الحد، ويختار أعلى درجة تلائمه. يحتفظ باتجاه الصورة وملف ألوان ICC عندما يتوفر؛ يحول بيانات الألوان الأخرى إلى sRGB. الشفافية تُركب على خلفية بيضاء، وتزال بيانات EXIF من النسخة المعدلة. يحتفظ الملف الأصلي بكل بياناته. تحويل الصور المتحركة إلى JPEG يستخدم أول إطار.

القص يأخذ بداية الفيديو، وينهيها على إطار كامل لا يتجاوز الحد. يستخدم يوتيوب Shorts عبر Buffer بحد 3 دقائق، وX بحد القناة المحدد في الخطة. عند اختلاف الأبعاد، يُحفظ المشهد كاملًا داخل إطار ذي هوامش؛ لا تُقتطع أطرافه. يُنتج الفيديو H.264 مع صوت AAC وامتداد MP4، ويُفحص الناتج ثانيةً قبل السماح برفعه.

تُنفذ عملية معالجة ثقيلة واحدة في الوقت نفسه. يمكن إلغاؤها؛ يحذف التطبيق الملف الجزئي ويحافظ على الأصل. يفحص المساحة المتاحة ويحتفظ بهامش يكفي لإعادة كتابة الفيديو أثناء تجهيزه. عند تغيير الملف بعد اختياره، يطلب اختياره مجددًا.

لا تمرر الواجهة مسارات ملفات إلى أوامر المعالجة؛ تستخدم مراجع داخلية تخص النافذة التي اختارت الملف. تعمل الأدوات في الخلفية دون نافذة طرفية، ولا تعتمد على تثبيت FFmpeg مسبقًا لدى المستخدم.

للمطور: شغّل `pnpm media:tools` قبل تشغيل Tauri للمرة الأولى. يسحب السكربت النسخة المثبتة في `tools/media-tools.json` ويتحقق من بصمة الأرشيف وجميع المكونات والترخيص قبل تجهيز الموارد. هدف الإصدار الحالي Windows x64؛ لا توجد نسخة أدوات غير متحقق منها للأنظمة الثانوية.

تستخدم هذه النسخة FFmpeg 9.0.2 من فرع الإصدار، ببناء LGPL 3 مع مكتبات مشتركة ودون x264 أو x265 أو مكونات GPL/nonfree. يسجل ملف المصدر الملحق بالتطبيق إصدار FFmpeg ومراجعة المصدر ومراجعة وصفة البناء. يجب إرفاق المصادر والتراخيص المطابقة عند توزيع الإصدار، ومراعاة [تعليمات FFmpeg](https://ffmpeg.org/legal.html) و[مصدر وصفة البناء المثبتة](https://github.com/BtbN/FFmpeg-Builds/tree/bd26828f0e965c2c657553584b09caf5d57eee52).
