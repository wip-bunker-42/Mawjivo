# تطوير Mawjivo والتحقق منه

ملف التطوير الخاص `mawjivo.secrets.env` يحتوي على مفاتيح التوقيع والنشر بنص واضح، وملف `mawjivo-device.secrets.env` يحتوي على بيانات استعادة ربط جهاز المستخدم. كلاهما محلي ومستبعد من Git. حفظ ملف التطوير خارج الجهاز مطلوب لمواصلة التوقيع والنشر بعد الفورمات؛ ملف نقل المستخدم لا يحمل مفتاح توقيع المشروع.

لإثبات النقل دون تغيير بيانات المستخدم، ابْنِ أداة المشغّل عبر `cargo build --manifest-path apps/desktop/src-tauri/Cargo.toml --locked --features operator-tools --bin setup` ثم شغّل `node scripts/accept-settings-transfer.mjs مسار-ملف-الجهاز مجلد-الأدلة`. تستخدم الأداة `--verify-transfer-file` للقراءة فقط و`--accept-transfer` لإنشاء SQLite وخزنة نظام معزولتين وفارغتين، وتستورد وتعيد التصدير وتقارن معرفات الموارد والمساحات والحسابات والمنشورات. تزيل بيانات الاختبار والمراجع التي أنشأتها فقط، وتحفظ دليلًا خاليًا من الأسرار. لا توزع أداة `setup` مع المثبت.

الإصدارات المثبتة موجودة في `tools/dependencies.json` وملف Rust وملف القفل. ثبّت Node LTS المذكور، ثم pnpm المذكور في `package.json` وأداة Rust مع rustfmt وclippy. لا تستخدم أداة وسائط موجودة في PATH؛ ينزل `pnpm media:tools` الحزمة الموثقة ويفحص كل مكوّن.

شغّل `pnpm install --frozen-lockfile` ثم `pnpm verify` للتحقق من الأنواع والاختبارات والبناء وخدمة Cloudflare وRust. شغّل `pnpm test:e2e` لفحص الواجهة، و`pnpm sync-version --check` لفحص نسخ التطبيق والخدمة. لتغيير الإصدار استخدم `pnpm sync-version 0.2.0` ثم أعد بناء حزمة الخدمة. لا تعدل رقمًا واحدًا فقط.

إذا منع الجهاز تشغيل Rust، لا تعطّل سياسة الحماية. استخدم نتيجة GitHub Actions لنفس commit للتحقق الأصلي، وشغّل `pnpm verify:js` محليًا. هذا الأمر يعلن ما فحصه ولا يدّعي فحص Rust. يبقى تشغيل المثبت الفعلي واختبار NVDA مطلوبين قبل تسليم النسخة.

يشغّل CI اختبارات الخدمة والواجهة وبناء ويندوز. تستخدم Actions بصمات SHA وصلاحية قراءة المستودع، دون مفاتيح الحسابات الشخصية. يمكن تشغيل فحص الترجمة الثانوية للينكس وماك يدويًا؛ مثبت ويندوز هو حزمة الإصدار المدعومة حاليًا. Dependabot يقترح التحديثات الأسبوعية، والتدقيق الأسبوعي يعلن مشكلات الحزم. تُراجع ترقيات الواجهة الرئيسية قبل دمجها.

يحظر `pnpm check:secrets` الرموز والمفاتيح المعروفة دون طباعة قيمها. يفحص جميع الملفات المتتبعة؛ لا يوجد استثناء عام للاختبارات. ملفات ENV والخزنة والمسودات ومفاتيح التوقيع وملفات المشغّل الخاصة لا تدخل المستودع أو حزمة الإصدار. تعتمد الحسابات المنشورة على خزنة جهاز المستخدم وخدمته الشخصية.

يبني `scripts/build-media-tools.sh` FFmpeg من مصدره المثبت مع OpenH264 وdav1d وJPEG XL وzlib-ng واعتمادياتها المطلوبة، ويحفظ البايتات الأصلية لكل المصادر وأدوات البناء والإشعارات. تضمن مكتبتا فك الصور تحويل AVIF وJPEG XL محليًا دون الاعتماد على عتاد معين، وتتيح zlib-ng الملف الوسيط PNG الذي يحافظ على الجودة أثناء التحويل. تعرض `Reproducible media tools` حزمة البصمات والمصادر للفحص؛ لا تستبدل الأداة المعتمدة حتى تنجح اختبارات الوسائط الأصلية وتُحفظ الحزمة والمصادر على خادم التنزيل الدائم. `pnpm notices` ينشئ نصوص إسناد اعتماديات النسخة المثبتة؛ يلزم تنزيل crates بواسطة Cargo قبل التغليف.

يجهز `node scripts/operator-downloads.mjs مسار-ENV-الخاص` مخزن تنزيلات الإصدار ونطاقه باستخدام Wrangler. يتحقق من علامة الملكية والتوجيه وسجلات DNS قبل الكتابة؛ هذا إعداد مستودع المشروع وليس إعداد خدمة حسابات المستخدمين. بعد التحقق من حزمة أدوات الوسائط، ينشرها `node scripts/operator-publish-media.mjs مسار-ENV-الخاص دليل-الحزمة` مع كامل مصادرها، ويتحقق من البصمات عبر الرابط العام. يحافظ على الملفات المنشورة ويحظر استبدال ملف إصدار ببايتات مختلفة. تُمرّر قيم الأسرار إلى Wrangler في البيئة فقط.

أي تغير في النشر أو الاستكمال يُختبر ضد عدم تكرار الكتابة. استجابة غير مؤكدة من منصة خارجية تحتاج فحصًا، ولا تعيدها الخدمة تلقائيًا. الاختبار الحقيقي على الحسابات الاجتماعية يحتاج مراجعة المحتوى وموافقة صاحب الحساب داخل التطبيق.

فحص RustSec الأول لم يجد ثغرات تمنع البناء، وأظهر تنبيهين معلوماتيين في اعتماديات GTK للينكس: `RUSTSEC-2024-0429` في `glib 0.18.5` و`RUSTSEC-2024-0370` في `proc-macro-error 1.0.4`. تأتي هذه الاعتماديات من إصدار Tauri المثبت والمتوافق. يحفظ التدقيق التنبيهين ولا يخفيهما؛ فحص الترجمة الثانوية لا يعني اعتماد إصدار لينكس للتوزيع قبل مراجعة مسار GTK. يحتوي ملف إشعارات إصدار ويندوز على قائمة الاعتماديات الفعلية لهذا الهدف.
